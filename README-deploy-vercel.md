نُبذة

هذه النسخة من المشروع جاهزة للنشر كـ موقع ثابت (Static) على Vercel.

ملفات مضافة:
- `vercel.json` — إعداد Vercel لنشر `index.html` كسيرفر ثابت وتمرير كل المسارات إلى `index.html`.

خيارات النشر السريعة

1) بالنشر عبر Vercel CLI (الأسرع - تحتاج حساب Vercel):

```bash
# تثبيت Vercel CLI (إن لم يكن مثبتاً)
npm install -g vercel

# تسجيل الدخول (سيفتح متصفح لتسجيل الدخول)
vercel login

# اذهب إلى مجلد المشروع (مثال):
cd "C:\\Users\\Admin\\Downloads\\cvvvv - Copy"

# نشر نسخة اختبارية
vercel

# نشر إلى الإنتاج
vercel --prod
```

بعد إكمال `vercel --prod` سيعرض CLI رابط النشر النهائي (مثال: `https://your-project.vercel.app`).

2) بالنشر عبر Git (GitHub/GitLab/Bitbucket):
- ادفع الشيفرة إلى مخزن Git (GitHub) ثم اربط المستودع بمشروع جديد في https://vercel.com/new.
- اختر الفرع المطلوب واضبط جذر المشروع (Root Directory) إلى `/` إن كنت تنشر من جذر المشروع.
- اضغط Deploy وسيعطيك Vercel رابط الموقع.

ملاحظات وقيود
- لا أستطيع تنفيذ النشر نيابة عنك لأن ذلك يتطلب الوصول إلى حساب Vercel أو دفع إلى مستودع GitHub باسمك.
- إذا تحب، أستطيع توليد أو تعديل ملفات إضافية (مثل `.vercelignore`، `CNAME`، أو `package.json`) قبل النشر.
- إن أردت أن أنشر أنا فعليًا، يمكنك: 1) إعطائي توكن Vercel (غير موصى به عبر الشات العام)، أو 2) ربط مستودع GitHub وإعطائي صلاحية كتابة (أو تزويدي برابط المستودع) — الأفضل أنك تقوم بعملية الربط بنفسك وشاركني الرابط بعد ذلك.

هل تريد أعدّل أي إعدادات إضافية (مثلاً وضع `cvvvv/` كجذر بدل `/` أو نقل الصور داخل المجلد `cvvvv/`)؟
